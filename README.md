# AEIOS Today: compare versions

https://rgafni.github.io/aeios-compare/

Tabs: Mine (copy of the live site, clock-controlled) · James (his mockup; his "now" markers moved to the demo time) · A · Calm · B · Focus · C · Timeline · D · Chat.

The day strip at the top sets the demo time (Thu Oct 8, 6:00 AM to 10:30 PM, 5-minute steps). Drag it to scrub, tap a block to jump to its start, or use the small Before school / In school / After school / Night jumps (demo only). Time is kept in the URL hash, e.g. `#a/t=10:30`.

All content is the showcase's sample data. No real student data.
