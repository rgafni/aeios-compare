# AEIOS Today: compare versions

https://rgafni.github.io/aeios-compare/

Tabs: Mine (copy of the live site, clock-controlled) · James (his mockup; his "now" markers moved to the demo time) · A · Calm · B · Focus · C · Timeline · D · Chat.

The **Preview time** bar at the top sets the demo time with one tap: Now, Morning 7:15, School 10:00, Lunch 11:30, After school 3:10, Homework 3:45, Dinner 6:30, Evening 8:30, Bedtime 9:30 (arrows step earlier/later; arrow keys work too). No dragging. Time is kept in the URL hash, e.g. `#a/t=10:00`. Installable: "Install app" in the bar (manifest + service worker; install.js + install.css).

All content is the showcase's sample data. No real student data.
